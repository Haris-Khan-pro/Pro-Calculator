## 🚀 Installation

```bash
git clone https://github.com/Haris-Khan-pro/Pro-Calculator.git

cd ProCalc-Web

python -m venv .venv

source .venv/Scripts/activate

pip install -r requirements.txt

uvicorn app.main:app --host 0.0.0.0 --port 8000
```
